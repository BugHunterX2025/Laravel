In Laravel, you can define a "hasOneThrough" relationship to access the user's phone number through the company. Here’s how you would set it up in your models:
class Student extends Model
{
    public function companyPhoneNo()
    {
        return $this->hasOneThrough(Phone_number::class, company::class, 'user_id', 'company_id', 'id','id');
    }
}

  public function index()
    {
        // $stu = Student::with('companyPhoneNo')->find(2);
        $stu = Student::with("company")->with('companyPhoneNo')->get();
        return $stu;
    }

php
Copy
Edit
public function oldestOrder() {
    return $this->hasOne(Order::class)->oldestOfMany();
}
🔍 Explanation:
hasOne(Order::class) – sets up a one-to-one relationship with the Order model.

oldestOfMany() – retrieves the earliest order (by date or created_at) from the related records.

You can also use latestOfMany() to get the latest order.
