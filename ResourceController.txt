** Type Of Controllers
    1. Basic Controllers
        -> php artisan make:Controller UserController

    2. Single Action Controller
        -> php artisan make : Controller UserController --invokable;
    
    3. Resource Controller (create ,update ,delete ,insert)
        -> php artisan make:Controller UserController -Resource
        ** Here Have Multiple Method
            1. public function index(){}
            2. public function store(Request $request){}
            3. public function show($id){}
            4. public function update(Request $request, $id){}
            5. public function destroy($id){}
            6. public function create() {}
            7. public function edit () {}
        *** not 7 methos use then
        Route::resource('users', UserController::class)->only(
    [
        'index',
        'create'
    ]
);
 Route::resource('users', UserController::class)->except(
    [
        'index',
        'create'
    ]
);

** Change Route Name 
    
Route::resource('users', UserController::class)->names([
    'index' => 'users.index',
]);

    User -> Comments
    Route::resource('user.Comments',usercommentController::class)

    Route::resource('user.Comments',usercommentController::class)->shallow();
